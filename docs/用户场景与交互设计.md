# 用户场景与交互设计

## 一、产品定位

视频字幕助手不只是“导出字幕”工具，而是在观看、定位、理解和整理视频内容之间建立一条连续工作流。

双界面不是重复功能，而是分别承担两种注意力模式：

- **播放器旁滚动面板**：低操作、强同步，服务于“我正在看”。
- **浏览器侧边栏**：高信息密度、强检索，服务于“我要查、找、跳、复制和导出”。

## 二、核心场景

### 1. 普通观看

用户打开视频后不进行额外操作。插件自动识别视频、等待播放器就绪、选择上次使用的语言，然后在播放器旁显示字幕列表。

当前句保持在视图中部，上下文仍然可见。用户不需要在视频画面、YouTube 原生字幕和另一个窗口之间反复切换视线。

### 2. 密集学习

用户需要反复查找概念、代码名或术语。此时打开侧边栏，在完整字幕中搜索，点击匹配句直接跳转视频时间点。

搜索结果不改变原始字幕数据，清空搜索词后立即恢复完整列表。

### 3. 手动阅读上下文

用户向上滚动查看前文时，插件必须暂停自动跟随，否则下一个播放事件会将用户强行拉回当前句。

面板会明确显示“恢复跟随”，由用户决定何时回到实时字幕。点击任意字幕跳转后，自动跟随恢复。

### 4. 多语言和自动字幕

轨道选择器同时显示语言和字幕类型。用户切换轨道后，播放器旁面板和侧边栏必须同时切换，不出现两个界面使用不同语言的状态。

最后一次选择的语言会成为后续视频的首选；找不到同语言时，再按“人工中文 → 自动中文 → 人工其他语言 → 第一轨道”降级。

### 5. 站内连续切换视频

YouTube 和哔哩哔都会在不完整刷新网页的情况下切换视频。插件通过媒体标识而非普通 DOM 变化判定是否切换，并取消旧视频请求，防止旧字幕覆盖新页面。

### 6. 全屏与剧院模式

普通模式下，滚动面板优先放在视频页右侧区域。进入全屏后，面板进入全屏容器右上角；退出全屏后自动回到页面侧栏。

面板可收起，收起状态在后续视频中保留，避免打断娱乐性观看。

### 7. 获取失败和自动恢复

界面不以“有轨道”作为成功标志，只有字幕正文成功解析并提交后才进入就绪状态。

YouTube 请求按以下顺序降级：

1. 重放浏览器原生字幕请求。
2. 请求播放器实时轨道地址的多种格式。
3. 请求播放器重新开启目标轨道并捕获新请求。
4. 读取 YouTube 自带的转录面板。
5. 首次失败时延迟自动重试一次。

诊断信息只记录阶段、HTTP 状态、正文长度和解析条数，不记录完整字幕网址或会话令牌。

### 8. 加入队列后关闭视频

用户在推荐页或侧边栏把视频加入队列后，可以关闭视频标签页，不需要保持播放。Service Worker 先尝试已有页面/接口字幕；YouTube 页面链路不可用时，由 macOS host 用固定版 `yt-dlp` 重新盘点人工字幕、自动 CC 与翻译字幕，并只下载选中的轨道。确认没有可用平台字幕后，才交给本机模型完成整条音频转录。

队列语言是任务语义的一部分：

- `auto`：YouTube 无语言提示时走 Parakeet；Bilibili 无语言提示时走 Cohere。
- `zh`：普通话使用 Cohere。
- 欧洲语言代码：使用 Parakeet，并把明确语言条件传给模型。
- `yue`：只尝试平台字幕。平台没有粤语/可用字幕时显示明确限制，不静默改用普通话。

队列结果保存平台字幕的语言与人工、自动 CC、翻译类型；卡片必须让用户看出结果来自 Bilibili/YouTube 平台字幕、Parakeet 还是 Cohere。失败卡片显示稳定错误码、经过脱敏的处理建议和可重试性；不得把签名 URL、HTML 或原生异常原文直接放进界面。

### 9. 本机能力不完整

队列页分别显示 yt-dlp、Parakeet、Cohere 状态。yt-dlp 缺失会影响关闭标签页后的 YouTube 字幕兜底和 YouTube 音频获取，不能把 Bilibili 标记为不可用；Cohere 文件存在但缺少有效词表或 `k_cache_0` 时显示模型不兼容。位于 `~/Library/Caches` 的 Cohere 模型可能被系统清理，界面因此允许重新检查并给出部分就绪状态。

长视频转录期间，30 秒心跳会维持扩展端活动看门狗；最后一个本机请求结束后，空闲 Native Messaging 端口会自动断开，避免 Service Worker 与 host 长驻。用户取消、真正静默超时、浏览器关闭或 host EOF 都会取消作业并清理任务临时目录；下次恢复从持久任务状态重新解析，不复用过期 Bilibili 签名 URL。

## 三、全场景功能覆盖矩阵

当前功能分支覆盖以下生产力场景；Swift/CoreML 与真实媒体链路仍以 macOS CI 和实机门禁为准：

### 1. 基础播放与伴随阅读
- YouTube 与哔哩哔哩全场景（包含单视频、分P、合集、番剧及特别聚合活动页）字幕高精度解析。
- 播放器旁 Shadow DOM 伴随滚动面板，支持多行换行、字号微调与点击跳播。
- 侧边栏搜索、实时高亮、双向时间轴同步。

### 2. 合集与多分P批量收割 (Batch Harvest)
- 自动探测 B 站分P列表、电视剧/番剧季、UP 主自选合集与系列专栏。
- 多并发批量抓取，支持选择性逐 P 勾选。
- 自动打包为标准 ZIP（内含 TXT、SRT、VTT、JSON），生成带层级大纲与自然段落聚类的 **Merged Markdown** 知识库文档。
- 支持提取官方 DASH 纯音频流直链。

### 3. AI 课程图文分解与多模态学习工作台 (AI Visual Course Workbench)
- **两阶段视觉证据规划**：大模型（如 Gemini 3.7 Flash Thinking / Ollama / 本地兼容端点）主动阅读完整字幕并规划章节与核心板书/架构图关键帧时间点。
- **通道 A 自动精准截帧**：通过 DOM Canvas 自动跳转截取 1080P/4K 原画 WebP 并毫秒级自动复位播放状态，亦支持随时点击「📸 截当前帧」手工补充。
- **交互式图文讲义呈现**：笔记内嵌高清板书卡片与 LaTeX 公式，点击图片右上角 `▶ MM:SS` 直接跳转回放。
- **Obsidian / Notion 专属图文包**：一键导出包含 `images/` 子目录与去重图片的 `.zip` 压缩包。
- **按视频持久化缓存**：切换标签页或重启扩展，历史生成的讲义毫秒级自动恢复呈现。
- **经典提示词库**：保留吞音纠错、长文速览、要点清单、难点辨析 4 大生产力提示词模板，支持一键复制到外部 AI 工具。

### 4. 订阅追踪中心与无人值守自动抓取 (Tracker & Unattended Harvest)
- 一键订阅关注 UP 主或专题课程合集。
- 后台 Alarm 周期自动巡检，发现新发布视频后自动拉取字幕并转换为 Markdown 缓存。
- 卡片内一键复制 Markdown、原位展开阅读、批量合并复制所有未读更新字幕。
- 扩展徽标未读红点提示与系统桌面通知。

### 5. 后台整视频转录

- Bilibili/YouTube 视频无需打开或播放即可完成平台字幕抓取；YouTube 关闭页链路由 host 的固定版 `yt-dlp` 完成。
- 平台字幕为空时，对支持语言调用本机 CoreML；粤语保持平台字幕限定。
- 任务具备单执行器租约、崩溃恢复、移除/清空/重试取消、长任务心跳和非空结果门槛。
- 能力面板区分未安装、部分就绪、组件可用和模型不兼容。
